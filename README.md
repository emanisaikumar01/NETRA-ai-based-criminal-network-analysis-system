# NETRA

## AI-Based Criminal Network Analysis System

NETRA is an AI-powered investigative intelligence platform designed to
analyze structured and unstructured crime-related data, uncover hidden
relationships, detect suspicious patterns, identify important network
entities, and assist investigators with explainable intelligence.
